# DaisyFM

## Author

Henrik Forssell

## Description

DaisyFM is a stereo FM radio-style WAV sampler for the Daisy Patch eurorack module.

The module streams radio stations from stereo WAV files named RadioStation-[1-6].wav on the SD card.

Ctrl 1: Frequency tuning between the 6 stations
Ctrl 2: Transmit gain
Ctrl 3: Noise floor
